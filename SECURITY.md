# Reporting a security concern

Use **Report a vulnerability** in this repository's Security tab if private
reporting is enabled. Its availability is a repository setting, not established
by this file.

If no private reporting channel is shown, open a minimal issue asking the
maintainer for a private contact method. Do not include exploit details,
credentials, account data, private session transcripts, or a crash dump
(.dmp file) in that public request.

A private report should include the affected commit or version, platform,
reproduction steps, impact and a minimal synthetic example. Remove secrets
from logs and attachments before sending them. A crash dump is a raw snapshot
of process memory, not a log: scrub it or describe the crash instead unless
the maintainer specifically asks for the dump itself.

This project does not currently publish a security-support window or a response
time commitment. This reporting policy makes no claim about a security audit.
